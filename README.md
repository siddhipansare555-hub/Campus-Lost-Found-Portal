# Campus FindIt

Campus FindIt is a full-stack web application developed using the MERN stack to simplify the process of reporting and tracking lost and found items within a college campus.

## Overview

Students often lose personal belongings on campus, while found items may remain unclaimed due to the absence of a centralized reporting system. Campus FindIt provides a single platform where users can report lost items, report found items, and browse existing records.

## Features

- User Authentication
- Report Lost Items
- Report Found Items
- View Lost Item Records
- View Found Item Records
- MongoDB Database Integration
- RESTful API Architecture

## Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Campus-FindIt.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
node server.js
```

## Environment Variables

Create a `.env` file inside the server directory:

```env
MONGO_URI=your_mongodb_connection_string
```
